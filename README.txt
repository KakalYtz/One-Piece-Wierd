WEIRD RPG V26 — LEIA ANTES DE USAR

1. Extraia o ZIP. A pasta principal do projeto é `weird-rpg`.
2. Abra essa pasta no VS Code. Mantenha juntos index.html, style.css, script.js, manifest.webmanifest, sw.js e icons/.
3. Para testar no computador, use uma extensão de servidor local (ex.: Live Server). Para instalar como app no celular, publique em HTTPS.
4. Não misture arquivos de versões anteriores. Substitua a pasta inteira pela pasta `weird-rpg` desta versão.
5. Dados de fichas, Homebrew, campanha e mapa ainda ficam neste navegador (localStorage). Não são sincronizados automaticamente entre dispositivos.

NOVO NA V26
- Opções: tamanho da interface de 85% a 130%.
- Ameaças: importar/exportar cada ameaça e fazer backup das ameaças Homebrew.
- Akuma no Mi: importar/exportar frutas individuais e backup das frutas Homebrew.
- Campanha: Mapa com imagem de fundo, tokens de agentes/ameaças, objetos/animais, tokens de imagem, grade, arraste e exportação/importação JSON.
- Cabeçalho da mesa deixa de ficar fixo durante a rolagem.
- Imagem da ameaça preenche o quadrado do avatar.
